# GxP Validation Templates – GitHub practice repo

Practice repository for learning GitHub with GxP validation documents.

## Contents
- `OQ-testscript-template.md` – Operational Qualification test script template

## Way of working
- `main` = approved version. Never edit it directly.
- All changes go through a branch and a pull request (PR).
- A PR must be reviewed before merge (= review/approval).
- The commit message states *what* changed and *why* (= reason for change).
